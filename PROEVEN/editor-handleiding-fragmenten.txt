ctp\save\mp from within the Windows Desktop environment.  Changing the folder name after creating it, may cause problems with starting multiplayer games.Carefully place Tile Improvements. The following is the only method of removing Tile Improvements: place a City or Unit on the tile and then use the "kill" toggle to kill it.Placing Units or Cities during the map editing process exposes areas of the Map.  Removing Units or Cities does not conceal these exposed portions of the Map, which will remain exposed when the game is ready to be played. To prevent this, click 
 to reset the Line-Of-Sight to the existing Units Vision Range.Granting an Advance and then removing its pre-requisite Advance, may cause problems.Selecting New Game from the Options menu while any of the Cheat Mode Windows are open (i.e. Terrain, Edit City, etc.) may cause problems.Zooming the Map all the way out and then placing Tile Improvements may cause problems.Editing prevents adjusting the following Multiplayer Game Setup options: Dynamic Join, Speed Turns, and Exclusions.Do not place Start Locations in Water or Space.Do not place two or more Start Locations in the same Tile.Do not use the Map Editor immediately after playing multiplayer. You must first restart Civilization: CTP, and then use the Map Editor to create your own Custom Maps/ Scenarios.C) Instructions and Notes on Using the Editor/Cheat Mode:Use the Launch Editor button from the Single Player New Game screen to launch the Editor. This uses the selected Game Settings (number of Civilizations, Map size, Difficulty, etc
) to start a new game in Editor Mode. This does not affect scoring for the current game or Saved Games. Use the Cheat Mode button from the Option menu after starting a game to invoke Cheat Mode. This invalidates the scoring for the current game, but not for Saved Games.Loading from a Saved Game counts scoring even if the Cheat Mode or Editor had been used to create the Saved Game.The Main Toolbar has the following three sections: World Settings, Player Settings and Save Game.World SettingsThe World Settings section allows editing of the following items:Difficulty: Click on this button to cycle through the various difficulty settings.Game Year: Change the Year by using the plus and minus buttons.Hide Map: Click this to conceal all areas of the Map except those within the Player
s Line-Of-Sight.Pollution: Set the global pollution level. The maximum pollution level equals the pollution generated by all players during the most recent turn of the game.  The global pollution level is a historical value, while the player pollution is recalculated each turn.  The thermometer bar displayed on the pollution window identifies the positions in the pollution continuum at which there will be pollution events.  The Os and Fs represent Ozone Damage and Flooding. A display indicates what type of pollution disaster will occur next and the estimated number of turns until it will occur.Reset LOS: Click this button to reset the Line-Of-Sight to the current Units
 Vision Range.Show Map: Expose the entire map and all game items, including Enemy Cities, Stealth Units, Tile Improvements, etc
 Settlers begin when starting a new game based on the customized Map.Choose

This function does not save any other information, including the following: Advances, Cities, Units, Tile Improvements, Line-of-Sight, or Diplomacy. Terrain: Edit the following items on the Map: Terrain, Goods, and Goodie Huts. Change a single Tile by selecting a Terrain Type then clicking on the desired Tile. Change multiple Tiles by painting the Map with the selected Terrain by clicking and moving the cursor with the mouse button depressed. Clicking on a Tile with a Good, River or Goodie Hut selected toggles the item in the Tile to On or Off.Player SettingsThe Player Settings section allows editing of the following items for the Civilization selected:(Click the + and - buttons to switch between civilizations)Advances: Add or remove Advances from the selected Civilization.Civ: Select the Tribe and gender for the currently selected Player. All Civilizations currently used by another Player are grayed out to indicate they are not available.  In the current release, the leader name is only editable for the first Civilization. Changing Civilizations after building Cities does not rename the Cities, so pick Civilizations first.Edit City: Select the Player on the main toolbar before selecting a City.  Then select a City by clicking on it, using the Next City button, or by using the keyboard shortcut.  Set the size and name of the City on the Edit City Window.  With the Edit City Window open, Rush Buy does not cost Gold (you can Rush Buy Units, Improvements and Wonders in the Production Tab without paying the item
s Gold cost). To quickly give a city many items, create a long queue and click on "Rush Buy" many times until the queue is empty. Use the Civ Status Screen to change the selected Civilization's Government.Gold: Add Gold to the selected Civilization
s treasury.Public Works: Add PW to the selected Civilization.Tile Imp: Place Tile Improvements for the selected Civilization without spending Public Works (PW). Click this button before opening the Tile Improvement Window. Placing Tile Improvements follows normal rules (pre-requisites and location), but the Improvements appear instantly and without costing PW.Unit/City: Place Units and Cities for the selected Player. Choose the Cities tab to place Cities (size 1-20) instantly. Use the Edit City window to change the size of a City to make it bigger than 20. Toggle 
 in order to select a Unit for which the Player does not have the required Advance. Use the "Kill" button to remove Cities and Units.
